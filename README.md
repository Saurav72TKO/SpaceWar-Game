# 🚀 Space-War

A simple 2D space shooter game built using **Python and Pygame**. Control your spaceship, shoot incoming aliens, and score points while defending yourself!

## 🎮 Features

- **Player Movement:** Move your spaceship left and right using the arrow keys.
- **Shooting:** Fire bullets using the Spacebar.
- **Alien Enemies:** Fight multiple aliens with increasing movement speed as your score grows.
- **Score Tracking:** Earn points by destroying aliens.
- **Sound Effects and Music:** Includes shooting sounds, collision effects, warning sounds, and background music.
- **Game Over System:** The game ends when an alien touches the player's spaceship or reaches the bottom of the screen. The final score and game-over music are displayed.

## 🛠️ Built With

- Python
- Pygame

## 🚀 How to Run

1. Install Python 3.x.
2. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Download or clone this repository.
4. Run the updated game file:

   ```bash
   python space_war_updated.py
   ```

**Important:** Please run `space_war_updated.py` to experience the newly added Game Over system. The original files are also included so you can compare the changes.

Make sure all required images, fonts, and audio files are in the same folder as the Python file.

## 🕹️ Controls

| Key | Action |
|---|---|
| ⬅️ Left Arrow | Move left |
| ➡️ Right Arrow | Move right |
| Spacebar | Fire bullets |
